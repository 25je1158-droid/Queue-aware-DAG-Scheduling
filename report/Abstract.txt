Vehicular Edge Computing (VEC) enables computation-intensive and latency-sensitive applications to offload tasks to nearby Mobile Edge Computing (MEC) servers. In a dynamic vehicular environment, vehicle mobility, wireless communication conditions, heterogeneous server capacities and changing server queues influence task completion time. These challenges become more complex when an application contains interdependent tasks represented as a Directed Acyclic Graph (DAG).

This project implements a queue-aware online DAG scheduling and task-offloading simulation. The framework replays vehicle mobility generated using SUMO, identifies dependency-ready tasks, estimates communication and server workload delays, screens MEC candidates using coverage and an estimated contact-time constraint, and selects a feasible MEC server using an earliest predicted completion-time heuristic. Each MEC server maintains a waiting queue and supports a limited number of concurrent tasks. CPU capacity is dynamically shared among running tasks in proportion to their task-specific critical-path ranks.

The implementation is evaluated against Random, Nearest and Highest-CPU server-selection baselines. The simulation records task completion, application completion time, queue waiting time, upload time, execution time, server utilization and deadline outcomes. Repeated experiments vary the selected vehicle count and task-generation seed while reusing the same SUMO mobility trace. The proposed method is a heuristic implementation of the stated minimization objective; it does not guarantee a globally optimal solution. The radio, queue-prediction and mobility-contact models are simplified simulation approximations.
